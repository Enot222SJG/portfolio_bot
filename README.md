# Бот-портфолио

Telegram-бот для хранения и демонстрации твоих проектов и навыков.

## Функциональность

- Хранение информации о проектах: название, описание, ссылка, статус
- Хранение навыков, использованных в проектах
- Связь проектов и навыков (связь многие-ко-многим)

## Структура базы данных

- `projects` — таблица проектов
- `status` — статусы проектов
- `skills` — навыки
- `project_skills` — таблица-посредник для связи проектов и навыков

## Запуск

1. Установи зависимости: `pip install pyTelegramBotAPI`
2. Укажи токен бота в `config.py`
3. Создай таблицы: `python logic.py`
